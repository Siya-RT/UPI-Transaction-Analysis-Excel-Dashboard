# 📊 UPI Transaction Analysis – Excel Dashboard

An interactive **UPI Transaction Analysis Dashboard built using Microsoft Excel** to analyze transaction performance, payment behavior, transaction status, fraud, banking trends, UPI applications, transaction types, and state-wise transaction amounts.

This project transforms raw UPI transaction data into an interactive and visually engaging dashboard that provides a consolidated view of key transaction metrics and trends.

---

## 📌 Project Overview

Digital payments and UPI transactions generate large volumes of data that can be difficult to analyze using raw datasets.

This project uses **Microsoft Excel** to transform transaction-level data into an interactive dashboard containing KPIs, charts, filters, and geographical analysis.

The dashboard helps users quickly understand:

- Overall UPI transaction volume
- Total transaction amount
- Cashback generated
- Transaction success rate
- Suspended/fraud transactions
- Transaction trends across age groups
- UPI application usage
- Transaction status
- State-wise transaction amounts
- Bank-wise transaction amounts
- Transaction type performance
- Gender-wise transaction activity

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze overall UPI transaction performance.
2. Track total transaction volume and transaction value.
3. Analyze transaction success and failure rates.
4. Identify suspended/fraud transaction activity.
5. Compare transaction behavior across different age groups.
6. Analyze the usage of different UPI applications.
7. Understand transaction distribution by status.
8. Compare transaction amounts across banks.
9. Analyze different transaction types.
10. Compare transaction amounts across Indian states.
11. Provide an interactive dashboard for easier data exploration.
